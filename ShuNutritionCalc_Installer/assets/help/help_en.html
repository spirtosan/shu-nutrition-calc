Language Switching

Three buttons at the bottom of the sidebar — EN, RU, BG — switch the interface language instantly. The active language is highlighted in amber and is remembered between sessions.

2 · Meal Builder

Adding Food Items

  1. Type in the Search box — list filters as you type
  2. Click a food to select it — focus moves to Weight (g) automatically
  3. Enter a weight and press Enter or click + Add to Meal
The meal ingredient list is read-only. To change a weight, double-click the row to remove it, then add it again at the correct weight.

Summary Labels

  • WHOLE MEAL WEIGHT — total grams, labelled RAW or PREPARED
  • WHOLE MEAL — total P / F / C / kcal
  • PER 100g — concentration per 100g (highlighted in amber)
  • Portion row — macros for any portion size you type

Impossible Value Warning

A red warning appears if per-100g kcal exceeds 900 (physical maximum = pure fat) or if P+F+C per 100g exceeds 100g. Both indicate incorrect database entries — find and fix them in the Database Manager.

Portion and "Use Whole Meal as Portion" Checkbox

The Portion (g) field calculates macros for any serving size. The Use whole meal as portion checkbox controls what gets pre-filled when you click Add to Journal:

SituationPortion pre-filled in Add to Journal dialog
Portion field has a valueThat value — always wins
Portion field empty + checkbox ONWhole meal weight (prepared if available, else raw)
Portion field empty + checkbox OFFEmpty — you type it in the dialog

The checkbox state is saved between sessions.

Action Buttons

3 · Prepared Food Weight — Physics & Rules

Why Enter a Prepared Weight?

When you cook food, water evaporates (roasting, frying, baking) or is added then drained (boiling). Weigh the finished dish and enter that weight. The app then calculates per-100g and per-portion values based on the actual cooked weight, which is what you eat from.

The Core Physics Rule

Only water changes during cooking. Protein, fat, carbohydrates and calories stay in the dish.

Total P/F/C/kcal are identical for raw and prepared views. What changes is the concentration per 100g — the same nutrients in a different weight of food.

Valid Prepared Weight Range

LimitRuleReason
Maximum≤ raw total weight Cannot gain mass without adding an ingredient. Add absorbed water as an ingredient (0 macros, real weight) for boiling.
Minimum≥ P + F + C (dry macro mass) Protein, fat and carbs cannot evaporate — only water can.
⚠ Example: a meal has 200g carbs + 50g fat + 30g protein = 280g dry mass. A prepared weight of 200g is rejected — the app shows the minimum allowed.

Zero-Macro Ingredients (Water, Salt, Baking Soda…)

These have weight but no calories. Add them to your database and include them as ingredients so the raw weight and floor check are calculated correctly:

IngredientPFCkcal
Water0000
Salt0000
Baking soda / powder0000

Boiling / Weight-Gaining Cooking

Pasta, rice, and legumes absorb water and get heavier. Add water as an ingredient (only the absorbed amount matters in the final weight), then enter the drained cooked weight as the prepared weight. Example: 80g dry pasta + 500g water → 200g cooked pasta. Raw weight = 580g, prepared = 200g, floor = ~75g dry macro mass — all valid.

Weight Loss vs Moisture Loss

When a valid prepared weight is entered, the status line shows both figures:

  • Weight loss — how much lighter the dish is vs raw total weight
  • Moisture lost — what fraction of the raw water content evaporated

4 · Database Manager

All foods are stored as per-100g values. When you add a food to a meal, the app scales values to the weight you enter.

Adding a New Food

  1. Fill in name, protein, fat, carbs per 100g
  2. kcal auto-calculates (P×4 + F×9 + C×4)
  3. Click Save to DB
⚠ P + F + C cannot exceed 100g per 100g of food. Maximum kcal/100g is 900 (pure fat). Pure sugar or pure protein = 400 kcal/100g.

Recipes

When you save a meal as a recipe from Meal Builder, it is stored at per-100g values with a [R] prefix. Recipes behave exactly like individual foods in search.

Deleting

Select an entry and click Delete Selected Product. Deletions are immediate — no undo.

5 · Journal

Logging a Meal from Meal Builder

Click Add to Journal. The dialog asks for:

  • Meal name — last used name is pre-filled
  • Date/Time — defaults to now; uncheck to enter manually (DD-MM-YYYY HH:MM)
  • Portion (g) — required; pre-filled per Meal Builder rules (section 2)
  • Notes — free text

The live preview shows kcal / P / F / C for the entered portion, updating as you type. If prepared weight was set, the preview uses the prepared concentration automatically.

Add Manual Entry

Click ➕ Add Entry to log a meal without Meal Builder — useful for meals eaten out. You can enter kcal only. For full P/F/C tracking, use Meal Builder.

Period Selector

Choose from: Today, Yesterday, Last 7 Days, Last 30 Days, Last Month, Last Year, or Custom (calendar picker, Monday start, DD-MM-YYYY).

Period Summary

Shows average kcal / P / F / C per day for the selected period. Missing days are flagged in an amber warning bar. You can choose to:

  • Show entries only — count only days with data
  • Include empty days (avg=0) — count empty days as zero
  • Fill missing days… — step through each missing day and skip, zero, or enter manually

Journal List Columns

ColumnContents
Date / TimeWhen the meal was logged (DD-MM-YYYY HH:MM)
Meal NameName entered at log time
Portion (g)Grams eaten
kcalCalories for that portion
P / F / C (g)Macros for that portion

Editing Entries

Double-click a row or select and click ✏ Edit Selected. All fields are editable for v5.1+ entries. Older legacy entries show values read-only; name, date, and notes are still editable.

7 · How Calculations Work

Calorie Formula (Atwater General Factors)

kcal = (Protein × 4) + (Fat × 9) + (Carbohydrates × 4)

Physical reference limits:

  • Maximum kcal/100g = 900 — pure fat
  • Pure carbohydrate or pure protein = 400 kcal/100g
  • P + F + C cannot exceed 100g per 100g of food

Prepared Weight — Totals vs Concentration

-- Whole-meal TOTALS are unchanged --
prepared_P    = raw_P
prepared_F    = raw_F
prepared_C    = raw_C
prepared_kcal = raw_kcal

-- CONCENTRATION rises because weight falls --
per_100g_X = total_X / weight × 100

-- Valid range --
min_prepared_weight = P_total + F_total + C_total  (dry macro mass)
max_prepared_weight = raw_total_weight

Per 100g and Portion

per_100g_X = total_X / ref_weight × 100
portion_X  = total_X / ref_weight × portion_g

Recipe Saving

recipe_X_per_100g = total_X / total_raw_weight × 100

Stored as per-100g so the recipe can be used like any other food item.

9 · Compiling from Source

Requirements

pip install customtkinter tkcalendar pyinstaller

Source File Structure

shu_nutrition_calc.py   ← entry point, window, sidebar, language switcher
config.py               ← constants, file paths, defaults
models.py               ← data I/O, all calculations
lang.py                 ← translation engine, t() function
ui_meal_builder.py      ← Meal Builder tab
ui_database.py          ← Database Manager tab
ui_log.py               ← Journal tab + all dialogs
ui_print.py             ← HTML report generation
lang/
  lang_en.json          ← English strings
  lang_ru.json          ← Russian strings
  lang_bg.json          ← Bulgarian strings
help/
  help_en.html          ← English manual
  help_ru.html          ← Russian manual
  help_bg.html          ← Bulgarian manual

Build Command (Windows)

python -m PyInstaller --onefile --noconsole ^
  --collect-all customtkinter ^
  --collect-all tkcalendar ^
  shu_nutrition_calc.py

After compilation, place the following next to ShuNutritionCalc.exe in the dist/ folder:

  • lang/ folder with all three JSON files
  • help/ folder with all three HTML files
  • Optionally: db/ folder with pre-built food databases
⚠ Run the .exe from dist/, not from inside build/. Data files are always created next to the executable.
