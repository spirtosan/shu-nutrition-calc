Переключение языка

Три кнопки внизу боковой панели — EN, RU, BG — мгновенно переключают язык интерфейса. Активный язык выделяется янтарным цветом и сохраняется между сеансами.

2 · Конструктор блюд

Добавление продуктов

  1. Введите запрос в поле Поиск — список фильтруется по мере ввода
  2. Нажмите на продукт для выбора — фокус автоматически перейдёт на поле Вес (г)
  3. Введите вес и нажмите Enter или кнопку + Добавить в блюдо
Список ингредиентов блюда — только для чтения. Чтобы изменить вес, дважды щёлкните по строке для удаления, затем добавьте продукт снова с нужным весом.

Итоговые показатели

  • ВЕС ВСЕГО БЛЮДА — общий вес в граммах, помечен СЫРОЕ или ГОТОВОЕ
  • ВСЕГО — суммарные Б / Ж / У / ккал
  • НА 100г — концентрация на 100г (выделена янтарным)
  • Строка порции — БЖУ для любого размера порции

Предупреждение о недопустимых значениях

Красное предупреждение появится, если ккал/100г превысят 900 (физический максимум = чистый жир) или Б+Ж+У/100г превысят 100г. Оба случая указывают на ошибки в базе данных — найдите и исправьте их в разделе «База данных».

Порция и чекбокс «Целое блюдо как одна порция»

Поле Порция (г) рассчитывает БЖУ для любого размера порции. Чекбокс Целое блюдо как одна порция определяет предзаполнение при нажатии «Добавить в дневник»:

СитуацияПредзаполнение порции в диалоге
Поле порции заполненоЭто значение — всегда приоритетное
Поле пусто + чекбокс ВКЛЮЧЁНВес всего блюда (готового или сырого)
Поле пусто + чекбокс ВЫКЛЮЧЕНПусто — введите в диалоге вручную

Состояние чекбокса сохраняется между сеансами.

Кнопки действий

КнопкаДействие
Сохранить как рецептСохраняет блюдо в базу данных как запись на 100г. Префикс [R] добавляется автоматически.

3 · Вес готового блюда — физика и правила

Зачем вводить вес готового блюда?

При готовке вода испаряется (запекание, жарка) или добавляется и сливается (варка). Взвесьте готовое блюдо и введите этот вес. Программа рассчитает значения на 100г и на порцию на основе фактического веса приготовленного блюда — именно столько вы едите.

Основной физический принцип

При готовке изменяется только вода. Белки, жиры, углеводы и калории остаются в блюде.

Суммарные Б/Ж/У/ккал одинаковы для сырого и готового. Меняется лишь концентрация на 100г — те же питательные вещества в другом весе блюда.

Допустимый диапазон веса готового блюда

ОграничениеПравилоПричина
Максимум≤ суммарного сырого веса Нельзя увеличить массу без добавления ингредиента. Для варки добавьте воду как ингредиент (0 макросов, реальный вес).
Минимум≥ Б + Ж + У (сухая масса) Белки, жиры и углеводы не испаряются — только вода.
⚠ Пример: в блюде 200г углеводов + 50г жиров + 30г белков = 280г сухой массы. Вес готового блюда 200г будет отклонён — программа покажет минимально допустимое значение.

Ингредиенты с нулевыми макросами (вода, соль, сода…)

Они имеют вес, но не содержат калорий. Добавьте их в базу данных и включите в состав блюда, чтобы сырой вес и минимальный вес готового рассчитывались корректно:

ИнгредиентБЖУккал
Вода0000
Соль0000
Сода / разрыхлитель0000

Варка / блюда, набирающие вес

Паста, рис и бобовые впитывают воду и становятся тяжелее. Добавьте воду как ингредиент (важно только поглощённое количество в итоговом весе), затем введите вес сваренного и откинутого блюда как вес готового. Пример: 80г сухой пасты + 500г воды → 200г варёной пасты. Сырой вес = 580г, готовый = 200г, минимум ≈ 75г — всё корректно.

Потеря веса и потеря влаги

При вводе корректного веса готового блюда строка статуса показывает оба показателя:

  • Потеря веса — насколько блюдо стало легче по сравнению с сырым весом
  • Потеря влаги — какая доля исходной воды испарилась

4 · База данных

Все продукты хранятся как значения на 100г. При добавлении продукта в блюдо программа масштабирует значения под введённый вес.

Добавление нового продукта

  1. Введите название, белки, жиры, углеводы на 100г
  2. ккал рассчитываются автоматически (Б×4 + Ж×9 + У×4)
  3. Нажмите Сохранить в базу
⚠ Б + Ж + У не может превышать 100г на 100г продукта. Максимум ккал/100г — 900 (чистый жир). Чистый сахар или чистый белок = 400 ккал/100г.

Рецепты

При сохранении блюда как рецепта из Конструктора блюд оно записывается со значениями на 100г и префиксом [R]. Рецепты ведут себя в поиске точно как обычные продукты.

Удаление

Выберите запись и нажмите Удалить выбранный продукт. Удаление происходит немедленно — отмены нет.

5 · Дневник

Запись блюда из Конструктора

Нажмите Добавить в дневник. В диалоге нужно заполнить:

  • Название блюда — предзаполняется последним использованным именем
  • Дата/время — по умолчанию текущее; снимите галочку для ручного ввода (ДД-ММ-ГГГГ ЧЧ:ММ)
  • Порция (г) — обязательное поле; предзаполнение по правилам Конструктора (раздел 2)
  • Заметки — произвольный текст

Предпросмотр показывает ккал / Б / Ж / У для введённой порции в реальном времени. Если задан вес готового блюда, предпросмотр автоматически использует концентрацию готового.

Ручная запись

Нажмите ➕ Добавить запись для записи блюда без Конструктора — удобно для блюд из кафе или ресторана. Можно ввести только ккал. Для полного учёта Б/Ж/У используйте Конструктор блюд.

Выбор периода

Доступны варианты: Сегодня, Вчера, Последние 7 дней, Последние 30 дней, Прошлый месяц, Прошлый год или Произвольный период (календарь, неделя с понедельника, ДД-ММ-ГГГГ).

Сводка периода

Показывает среднесуточные ккал / Б / Ж / У за выбранный период. Пропущенные дни выделяются янтарным предупреждением. Вы можете:

  • Только записи — учитывать только дни с данными
  • Включить пустые дни (сред.=0) — считать пустые дни как нулевые
  • Заполнить пропуски… — пройтись по каждому пропущенному дню: пропустить, обнулить или ввести вручную

Столбцы журнала

Редактирование записей

Дважды щёлкните строку или выберите её и нажмите ✏ Изменить выбранное. Все поля доступны для редактирования в записях версии v5.1+. В устаревших записях значения показаны только для чтения; название, дата и заметки по-прежнему редактируются.

6 · Печать и экспорт

Отчёты создаются как HTML-файлы и автоматически открываются в браузере по умолчанию. Для печати на бумаге используйте Ctrl+P → выберите принтер или «Сохранить как PDF».

Печать блюда

Доступна в Конструкторе блюд после добавления хотя бы одного ингредиента. Все переключатели изначально выключены — выберите, что включить:

Всё блюдо — готовоеТе же итоги с весом готового блюда как ориентиром

7 · Как работают расчёты

Формула калорий (общие факторы Этуотера)

ккал = (Белки × 4) + (Жиры × 9) + (Углеводы × 4)

Физические контрольные ограничения:

  • Максимум ккал/100г = 900 — чистый жир
  • Чистые углеводы или чистый белок = 400 ккал/100г
  • Б + Ж + У не может превышать 100г на 100г продукта

Вес готового блюда — итоги и концентрация

-- Суммарные значения БЛЮДА не изменяются --
готовые_Б    = сырые_Б
готовые_Ж    = сырые_Ж
готовые_У    = сырые_У
готовые_ккал = сырые_ккал

-- КОНЦЕНТРАЦИЯ растёт, так как вес уменьшается --
на_100г_X = итого_X / вес × 100

-- Допустимый диапазон --
мин_вес_готового = Б_итого + Ж_итого + У_итого  (сухая масса)
макс_вес_готового = суммарный_сырой_вес

На 100г и порция

на_100г_X  = итого_X / опорный_вес × 100
порция_X   = итого_X / опорный_вес × граммы_порции

Сохранение рецепта

рецепт_X_на_100г = итого_X / суммарный_сырой_вес × 100

Хранится как значения на 100г, чтобы рецепт можно было использовать как обычный продукт.

8 · Файлы данных и резервное копирование

Все файлы находятся в той же папке, что и .exe. Ни реестра, ни AppData, ни скрытых файлов.

food_db.json

[
  {"name": "Куриная грудка", "p": 31.0, "f": 3.5, "c": 0.0, "kcal": 165.0},
  {"name": "Вода",           "p":  0.0, "f": 0.0, "c": 0.0, "kcal":   0.0}
]

meal_log.json — структура записи (v5.1+)

{
  "id":        "uuid4-строка",
  "datetime":  "2026-03-11T14:30:00",
  "meal_name": "Обед",
  "portion_g": 350.0,
  "p": 42.5, "f": 8.2, "c": 31.0, "kcal": 367.0,
  "notes": ""
}

settings.json

{"language": "ru"}

Хранит выбранный язык интерфейса. Создаётся автоматически при первом запуске.

Резервное копирование

Регулярно копируйте food_db.json и meal_log.json в облачную папку или на USB-накопитель. В этих двух файлах хранятся все ваши данные.

9 · Сборка из исходников

Зависимости

pip install customtkinter tkcalendar pyinstaller

Структура исходных файлов

shu_nutrition_calc.py   ← точка входа, окно, боковая панель, переключатель языка
config.py               ← константы, пути к файлам, значения по умолчанию
models.py               ← ввод/вывод данных, все расчёты
lang.py                 ← движок переводов, функция t()
ui_meal_builder.py      ← вкладка «Конструктор блюд»
ui_database.py          ← вкладка «База данных»
ui_log.py               ← вкладка «Дневник» и все диалоги
ui_print.py             ← генерация HTML-отчётов
lang/
  lang_en.json          ← строки на английском
  lang_ru.json          ← строки на русском
  lang_bg.json          ← строки на болгарском
help/
  help_en.html          ← руководство на английском
  help_ru.html          ← руководство на русском (этот файл)
  help_bg.html          ← руководство на болгарском

Команда сборки (Windows)

python -m PyInstaller --onefile --noconsole ^
  --collect-all customtkinter ^
  --collect-all tkcalendar ^
  shu_nutrition_calc.py

После компиляции поместите рядом с ShuNutritionCalc.exe в папку dist/:

  • Папку lang/ со всеми тремя JSON-файлами
  • Папку help/ со всеми тремя HTML-файлами
  • Дополнительно: папку db/ с готовыми базами продуктов
⚠ Запускайте .exe из папки dist/, а не из build/. Файлы данных всегда создаются рядом с исполняемым файлом.
